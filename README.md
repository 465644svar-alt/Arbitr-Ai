# Арбитр - Система управления чатами

Десктопное приложение для Windows для управления множественными чатами с нейросетями, включающая арбитраж ответов через GPT.

## Возможности

### 1. Клиентский чат
- **Добавление соединений**: Управление подключениями к различным API нейросетей
- **Поиск**: Фильтры и процедуры поиска
- **Командные вызовы**: Управление командными вызовами с строгим процессом
- **Запуск ролей**: Отправка всех настроенных ролей одновременно

### 2. Основной чат
- **Мультимодельная поддержка**: Интеграция с различными моделями AI
- **Временные метки**: Автоматическое добавление даты и времени к сообщениям
- **Ответы нейросетей**: Отображение ответов от всех подключенных нейросетей
- **Роль-задание**: Обратная связь от нейросети о выполнении ролевых задач

### 3. Управление ролями (I Роль)
- **Необходимость роли**: Описание целей и задач каждой роли
- **Выбор модели**: Поддержка GPT-4, GPT-3.5-turbo, Claude-3, Claude-2, PaLM-2, Gemini Pro
- **Создание промптов**: Индивидуальные промпты для каждой нейросети
- **Редактирование**: Возможность изменения созданных ролей

### 4. Запреты и задачи (II Запреты/Задачи)
- **Управление запретами**: Список ограничений для промптов
- **Задачи запретов**: Алгоритмы ответов нейросетей
- **Генерация отчетов**: Автоматическое создание отчетов о запретах и задачах

### 5. Настройки
- **API конфигурация**: Управление ключами API, endpoint'ами и timeout
- **Индикатор соединения**: Визуальный статус подключения
- **Автосохранение**: Опциональное автоматическое сохранение настроек
- **Импорт/Экспорт**: Сохранение и загрузка всех настроек

### 6. Логи работы
- **Полное логирование**: Запись всех действий в приложении
- **Экспорт логов**: Сохранение логов в текстовый файл
- **Очистка**: Управление историей логов

### 7. Арбитр GPT
- **Проверка вопросов/ответов**: Анализ ответов нейросетей
- **Верификация**: Проверка назначения ролей
- **Контроль качества**: Оценка ответов через промпт

## Системные требования

- **Операционная система**: Windows 10/11 (или Linux/MacOS с Python)
- **Python**: 3.8 или выше
- **RAM**: Минимум 4 GB

## Использование

### Первый запуск

1. Откройте вкладку **Настройки**
2. Введите API ключ и endpoint для вашей нейросети
3. Нажмите "Сохранить API настройки"
4. Проверьте соединение нажав "Проверить соединение"

### Создание роли

1. Перейдите на вкладку **I Роль**
2. Опишите необходимость роли в первом поле
3. Выберите модель из выпадающего списка
4. Введите промпт для создания роли
5. Нажмите "Сохранить создание"

### Работа с чатом

1. Перейдите на вкладку **Основной чат**
2. Введите сообщение в поле ввода внизу
3. Нажмите "Отправить"
4. Арбитр GPT автоматически проверит и обработает ваш запрос
5. Ответы от всех нейросетей будут отображены в разделе "Ответы всех нейросетей"

### Управление запретами

1. Откройте вкладку **II Запреты/Задачи**
2. Введите запрет в текстовое поле
3. Нажмите "Добавить запрет"
4. Аналогично добавьте задачи
5. Нажмите "Сгенерировать отчёт" для создания отчета

### Просмотр логов

1. Перейдите на вкладку **Логи работы приложения**
2. Все действия автоматически логируются
3. Используйте "Экспортировать логи" для сохранения в файл
4. "Очистить логи" для удаления истории

## Сохранение и загрузка данных

Приложение автоматически сохраняет все данные в файл `settings.json` при нажатии на "Сохранить все настройки" в меню Файл или на вкладке Настройки.

Сохраняемые данные включают:
- API конфигурацию
- Список соединений
- Роли и промпты
- Запреты и задачи
- Настройки автосохранения

## Горячие клавиши

- `Ctrl+S` - Сохранить настройки (планируется)
- `Ctrl+L` - Загрузить настройки (планируется)
- `Ctrl+Q` - Выход из приложения (планируется)

## Устранение неполадок

### Приложение не запускается

Убедитесь, что установлены все зависимости:
```bash
pip install --upgrade -r requirements.txt
```

### Ошибка подключения к API

1. Проверьте правильность API ключа
2. Убедитесь, что endpoint доступен
3. Проверьте настройки timeout

### Не сохраняются настройки

Убедитесь, что у приложения есть права на запись в директорию:
```bash
chmod +w .
```
